# EcoLens front-end

Next.js app (React, Tailwind CSS, shadcn, three.js) for EcoLens. See the main
[README](../README.md) for the project, data sources and credits.

```bash
npm install
npm run dev            # http://localhost:3000, uses the API in NEXT_PUBLIC_API_URL
npm run dev:fixtures   # offline, uses the example answers in fixtures/
npm run typecheck && npm run lint && npm run build
```
